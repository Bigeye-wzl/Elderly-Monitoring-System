# 前端（Web / 可视化大屏）

本目录存放系统前端代码：可视化大屏、H5 页面、移动端 Web 等，由协作者从 `smart-eldercare-fullflow` 迁入。

## 目录约定

- 前端框架代码按原项目结构整体放入本目录，不要把零散文件铺到仓库根目录。
- 依赖目录 `node_modules/`、打包产物 `dist/` 已在 `.gitignore` 中忽略，不要提交。
- 环境变量（`.env.local` 等）与接口密钥不要提交到仓库，仅保留本地副本。

## 开发

> 具体技术栈（Vue / React / Three.js 等）、安装与启动命令，待框架代码迁入后在此补充。
